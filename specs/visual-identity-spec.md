## 2. 视觉母体：蜂巢电波 (The Cellular Wave)

### 2.1 几何构图法则 (基于 100×100 标准视口)

1. **六边形外轮廓基座 (The Outer Hive)**
   - 形状：正六边形（顶点位于顶部与底部中央），尺寸：宽度 76px，高度 88px。
   - 顶点坐标：`(50,6)`, `(88,28)`, `(88,72)`, `(50,94)`, `(12,72)`, `(12,28)`。
   - 填充：深海暗夜蓝 `rgba(15, 23, 42, 0.90)`，与 Web 控制台 `--bg-primary` 完美融为一体。
   - 描边：3.5px 粗线条，应用琥珀金渐变 `url(#gradAmber)`（`#FCD34D` ➔ `#F59E0B` ➔ `#D97706`），转角圆滑连接（`stroke-linejoin="round"`）。
   - 光晕：柔和琥珀光晕滤镜（`flood-color="#F59E0B"`, `flood-opacity="0.35"`）。

2. **内部同心六边形蜂房内壁 (The Inner Cell Walls)**
   - 顶点坐标：`(50,18)`, `(78,34)`, `(78,66)`, `(50,82)`, `(22,66)`, `(22,34)`。
   - 填充：无。
   - 描边：1.8px 琥珀金半透明虚线 `rgba(245, 158, 11, 0.28)`，虚线参数 `stroke-dasharray="3 3"`。

3. **双重无线电通信弧线 (The Cellular Radio Waves)**
   - **外层大电波弧 (电光青蓝)**：
     - 起始于 `(32, 38)`，控制点 `(50, 24)`，终点 `(68, 38)`。
     - 描边：3.5px 纯净电光青蓝渐变 `url(#gradCyan)`（`#0284C7` ➔ `#38BDF8`），端点为平滑圆头（`stroke-linecap="round"`）。
   - **内层中电波弧 (高亮琥珀金)**：
     - 起始于 `(37, 50)`，控制点 `(50, 38)`，终点 `(63, 50)`。
     - 描边：4.0px 琥珀金渐变 `url(#gradAmber)`，圆头连接。

4. **发光通信中枢核 (The Core Hub Node)**
   - 中心坐标：`(50, 63)`。
   - 内实心核：半径 5.5px 实心琥珀金点。
   - 外呼吸光环：半径 10.5px，1.5px 细环，50% 透明度。

## 3. 极小场景（16×16 / 24×24）简化穿透法则

在浏览器 Favicon 与 Windows 16×16 任务栏极端小尺寸下，细微的虚线与双层弧线会被子像素抗锯齿吞没。
因此针对 16×16 建立如下穿透标准：
- 保留外层六边形轮廓（线宽加粗至 6px~8px 当量）；
- 内部仅保留单道饱满青蓝电波弧与实心金核；
- 确保在暗黑与明亮背景下，六边形与电波金点坚挺可辨，永不糊成一团。
