# 规范契约：蜂窝通信标准化术语与文案规范 (AIR-50)

全系统面向用户界面、API 响应、推送通知、MCP 描述与终端日志，必须统一遵循如下术语映射字典：

| 业务场景 | 淘汰的旧文案 (市井/廉价/推销) | 标准化的新文案 (专业/中性) | 映射原则与位置 |

| **移动数据关闭** | `已掐断蜂窝数据 (0 流量纯信令保号)`<br>`掐断板载蜂窝数据`<br>`0流量纯信令保号态` | **`已关闭移动数据`** | 遵循标准移动操作系统规范，杜绝“掐断”与“保号”等俗语（Web, Client, Hub, Bridge） |
| **移动数据开启** | `正在为【X】开启蜂窝数据...`<br>`走4G发HTTP` | **`正在开启【X】移动数据...`**<br>**`已开启移动数据`** | 统一名词为“移动数据” |
| **拨号弹窗看门狗标签** | `防扣费安全看门狗` | **`通话时限管理`** | `index.html:2744` 拨号弹窗表单标签 |
| **接听挂断复选框** | `对方一旦接听立即秒挂断（确保绝不产生通话费）` | **`对方接听后立即挂断`** | `index.html:2754` 拨号弹窗选项 |
| **拨号振铃选项** | `⏱️ 对方振铃 15 秒后自动挂断 (推荐·双方0话费)` | **`⏱️ 对方振铃 15 秒后自动挂断`** | `index.html:2746` 未接通本来即无费用，去除多余修饰 |

## 2. 协议与协议字段物理锁定（严格保护区）
以下底层协议字段必须保持 100% 原始字面量，严禁因文案清洗而改动：
- `cost = "0_toll"`（底层呼叫协议计费分类标记，板端 `call_service.lua`）
- `cellular_dial_phone`、`cellular_toggle_rndis`、`cellular_toggle_board_data`（对外导出的 FastMCP 工具函数原名）
- 串口 JSON 键名：`cellular_data`、`rndis`、`cmd`、`status` 等。
